# Goal 34 evidence package

The two run directories contain the native simulator-generated scenarios, Goal 24B generation manifests, Goal 19 experiment output, metrics, and JSONL event traces. The adjacent `manifest.json` files record run IDs, assumptions/provenance, decision metrics, and SHA-256 digests of the copied artifacts.

`goal32-policy-experiments.json` records the actual Goal 32 manager experiment and its one-worker/two-worker parity pair. Both policies completed with valid outputs and zero surface safety failures/collisions. For this single seed, both produced the same mean departure delay; no adaptive advantage is claimed.

`kauo-adaptive-closure` is the KAUO Goal 27 fixture with an explicitly assumed two-aircraft schedule and approximate taxiway geometry. The closure at 14:25:12Z causes the logged replacement route; this is a simulation demonstration, not observed airport activity. `goal33-plan-adaptive` preserves the imported schedule provenance from the Goal 33 Plan scenario; the source records are retained as imported operational data but have not been independently authenticated here.

`operator-intervention-live` contains a separate live-control replay using the same approximate KAUO fixture and the legacy SCRIPTED policy. It closes `twy_a_mid_fbo_primary` at simulation second 1504. The native event recorder captures `OPERATOR_INTERVENTION` replanning at second 1532 from `[6, 4, 3, 2]` to `[6, 7, 5, 4, 3, 2]`. The aircraft completes safely. This demonstrates operator update handling on the baseline policy and does not relabel the run as ADAPTIVE.

`goal33-live-update-replan` records a real Scenario Studio Live updates workflow using the imported synthetic KAUO schedule fixture. A versioned `closure_started` event with explicit simulator-apply selection maps through the configured Goal 24B route registry into a live Goal 34 ADAPTIVE session. It retains the operational session and event, generated native scenario, simulator event stream, metrics, and source-linked intervention log. At simulated second 1532, the agent re-planned from `[6, 4, 3, 2]` to `[6, 7, 5, 4, 3, 2]`; both aircraft objectives completed without failed objectives or surface/aircraft collision findings. The screenshot is `../screenshots/goal34-goal33-live-update-replan.png`. This is controlled simulator evidence, not evidence of real airport activity.
