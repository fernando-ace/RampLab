# Airside Sim

Airside Sim is a portable C++23 discrete-event simulation foundation for airport ramp operations. The engine is headless and presentation-independent so later milestones can integrate visualization and robotics adapters without coupling them to simulation state.

This repository is being developed milestone by milestone. The first milestone covers a small deterministic airport scenario, service-vehicle routing and contention, turnaround operations, metrics, a CLI demonstration, and automated tests.
